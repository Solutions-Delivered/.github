# Solutions Delivered Ltd

UK software company building and maintaining WordPress and WooCommerce plugins.

## How we work

- **Compatibility first:** every plugin is tested automatically against current, release candidate and nightly versions of WordPress, WooCommerce and supported PHP versions.
- **Security:** we follow the WordPress.org plugin guidelines, avoid tracking without consent, and handle vulnerability reports responsibly (see our [security policy](https://github.com/Solutions-Delivered/.github/blob/main/SECURITY.md)).
- **Transparency:** changelogs are public and every release goes through automated checks, including the official WordPress Plugin Check.
